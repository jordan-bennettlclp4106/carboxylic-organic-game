## What the Game Does

Carboxylic Hacker presents organic chemistry revision as a futuristic hacking mission. Players solve naming problems built around IUPAC rules, gaining practice with the structures and naming conventions found in organic chemistry.

Through a web-based mix of interactive exercises and rewards, the game offers students a repeatable way to review naming principles and develop chemistry skills. The cyberpunk setting adds motivation and context while serving as a supplement to regular instruction and course resources.
